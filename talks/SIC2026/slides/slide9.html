Two Audiences Now

Our code syntax is no longer written purely to be compiled down for local servers; it has two readers:

1. Human Engineers

Need semantic code layouts and clear logical separation to parse complex software modules and safely review pull requests.

  • Can a human review and comfortably extend this code?
  • Are boundaries and responsibilities clear at a glance?
  • Is the cognitive load manageable during code review?

2. AI Agents

Require clear interfaces, complete types, and schema boundaries to execute stable, hallucination-free edits.

  • Is the contract explicit enough for compilers to auto-verify?
  • Can AI read the full intent without guessing?
  • Are constraints machine-readable, not just human-readable?
