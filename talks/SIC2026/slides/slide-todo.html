Everything should be explicit

In the new world, everything should be explicit. Even things that traditionally haven't been — like solution and application architecture.

For example, the Onion Architecture has often been criticised for introducing boilerplate and unnecessary friction. In the age of AI agents, that friction becomes a feature. An architecture that can be formally described can also be formally verified.

Onion.config.json

{
  "layers": {
    "domain-model": "./src/domain-model",
    "domain-services": "./src/domain-services",
    "app-services": "./src/app-services",
    "infrastructure": "./src/infrastructure"
  },
  "rules": [
    {
      "from": "domain-model",
      "allowedImports": []
    },
    {
      "from": "domain-services",
      "allowedImports": ["domain-model"]
    },
    // ...
