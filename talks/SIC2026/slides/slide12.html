Predictions

If AI models reach a plateau, tools and practices that encode verification through explicitness will rise in popularity:

  • Static types become non-negotiable — TypeScript already won JavaScript. Python type hints and validated configs are next.
  • Effect systems go mainstream — Side effects tracked in the type signature, not buried in runtime surprises.
  • Schema-first protocols replace documentation — Protobuf, GraphQL schemas, and OpenAPI as the single source of truth.
  • NoSQL takes a hit — Foreign keys and constraints win over "flexible" document stores with no guarantees.
  • Architecture tests replace architecture diagrams — Executable rules, not Confluence pages nobody reads.
  • Explicit architecture patterns gain adoption (e.g. Actor Model, Hexagonal Architecture) — Replacing "best practices" wikis with enforceable structure.
