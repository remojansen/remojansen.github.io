What Rises in Value

As the costs of writing code fall toward zero, architectures, tools, languages, and patterns that prioritize easy, machine-executable verification are surging in value.

Flexibility-First (Slow AI Verification)

  • Schema-less Document Databases (NoSQL)

  • Dynamic Types (JS / Python)

  • Loosely-typed APIs (REST)

  • Implicit, undocumented side effects

  • Untracked Memory Management (C/C++)

  • Shared State Concurrency (Threads/Locks)

  • External Documentation (Confluence / Wikis)

Explicitness-First (Fast AI Verification)

  • Database Enforced Constraints (SQL)

  • Static Types (TS / Rust / Go)

  • Branded Types (eliminate order-dependent bugs at compile time)

  • Type Safe Contracts (Protobuf / gRPC)

  • Explicit, Declaratively Modeled Effects (FP)

  • Explicit Memory Ownership (Rust)

  • Explicit Message Passing (Actor Model)

  • In-Repo Documentation (Markdown / ADRs)

We must optimize for richer AI context and faster automated verification.
